# 写作助手 ✍️

一个纯前端的创作辅助工具，帮助你从"想写点什么"走到"写完一部作品"。所有数据保存在浏览器本地（localStorage），不需要联网、不需要后端、不上传任何内容。

## 功能

- **文本类型选择**：短篇小说 / 长篇小说 / 剧本 / 散文 / 诗歌 / 网络小说 / 童话 / 其他，不同类型对应不同的大纲模板与修订清单。
- **文笔偏好设置**：叙述人称、语气基调、节奏、句式偏好、参考作家/作品、目标读者、篇幅目标。
- **灵感启发**：主题、冲突、开篇金句、"如果……会怎样"、氛围意象，一键随机生成并可收藏；附带角色/地名生成器和灵感手记。
- **设定规划**：
  - 世界观（时代背景、地点、规则体系、阵营势力、历史大事记、设定边界）
  - 人物档案（外貌、性格、目标、恐惧、背景故事、人物弧光、人物关系）
  - 情节 / 事件时间线（可排序）
  - 大纲构建（三幕式 / 英雄之旅 / 起承转合 / 自由结构模板，支持章节与场景）
- **正文写作**：按章节写作，实时字数统计、全文字数、每日写作目标与进度条，一键导出全文为文本文件。
- **修订检查清单**：根据文本类型自动生成的自查清单。
- **多项目管理**：可同时管理多部作品，随时切换、重命名、删除。

## 如何运行

这是一个纯静态网页应用，用任意静态服务器打开 `index.html` 即可，例如：

```bash
# 方式一：Python 自带的静态服务器
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080

# 方式二：Node.js
npx serve .
```

也可以直接双击 `index.html` 在浏览器中打开（部分浏览器对本地脚本加载无限制，若无法正常运行请改用上面的静态服务器方式）。

## 数据存储说明

所有作品数据保存在浏览器的 `localStorage` 中，仅存在于当前浏览器/设备上。清除浏览器数据会导致作品丢失，请注意通过"正文写作"页面的导出功能定期备份重要内容。

## 项目结构

```
index.html              页面入口
css/style.css           样式
js/data.js               静态数据（文本类型、文笔选项、灵感库、大纲模板、命名库、修订清单）
js/utils.js              通用工具函数
js/storage.js            本地存储与项目 CRUD
js/views-*.js            各功能页面的渲染逻辑
js/app.js                主控制器：布局、路由、状态管理
```
